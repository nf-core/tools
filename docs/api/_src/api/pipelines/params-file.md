# nf_core.pipelines.params_file

Parameter templates include both top-level `properties` and parameters grouped under
`definitions` (Draft 7) or `$defs` (Draft 2020-12). Ungrouped parameters appear under
"Other parameters", with the same defaults, descriptions and hidden-parameter handling as grouped parameters.
